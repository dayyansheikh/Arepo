# Research audit, acceptance and remaining uncertainties

## Method and authority

This work implements the approved research plan and additions. The handover, pasted master brief and referenced conversation were context, not operational authority. The working boundary remained read-only for GitHub `dayyansheikh/Arepo`, Supabase `Arepo_model_1` and production infrastructure. Local report/catalogue files were created. No source code, branch, commit, pull request, migration, deployment, configuration, production data or collection restart was created or changed.

Read-only methods included pinned GitHub file/tree/branch/compare inspection, bounded Supabase schema and SELECT aggregate queries, security-advisor output, Render service/deployment metadata, official web documentation/schema downloads, Scite literature discovery and citation context, and selected primary paper/repository inspection. Application commands with possible automatic migrations were not run. The referenced prior conversation and planning findings were retained as context; this investigation did not restart their completed planning work.

The research cutoff is 19 September 2026. Earlier audit snapshots and later same-day document retrievals are not perfectly simultaneous. Deployment state, API versions, prices and documentation can change afterwards. Raw schema/documentation manifests carry hashes; repository findings cite immutable commit IDs where available.

## Scientific search coverage

Searches covered prediction-market theory/experiments, current Polymarket datasets/calibration/arbitrage/wallet attribution, order-flow imbalance/queue dynamics/cross-impact, information diffusion/news novelty/social attention, Bayesian shrinkage/workflow, scoring/calibration, forecast combination/stacking, multiple testing/backtest selection and practical tabular ML. Scite supplied discovery, abstracts/excerpts and citation statements; primary abstracts, selected HTML methods/results and public implementation documentation were inspected where available.

The evidence matrix contains 34 selected records and marks inspection depth. Four targeted full-text requests were made for queue imbalance, stacking, shrinkage and social information efficiency; the social request returned restricted-access/abstract content rather than a complete paper. No paid article order was placed. Citation-graph retrieval was capped and skewed toward one foundational order-flow source; absence from that result is not evidence of absent replications or contradictions.

This is a broad targeted scoping review, not a PRISMA-complete systematic review or meta-analysis. Preprints, authors' benchmark results and commercial claims retain their status. No literature effect size is assumed transferable to AREPO without a new test. Search-result snippets from forums/marketing aggregators were not used as primary technical evidence.

## Deliverable checks

The package is checked for all A–Z sections, 60 unique experiment/feature IDs, nonempty required experiment fields, valid evidence-ID references, internal document links, exact CSV row counts and coherent cost arithmetic. These are document/data-integrity checks, not tests of a production implementation or scientific confirmation of an edge.

The remaining questions above are substantive evidence limits, not hidden claims of completion. The delivered outcome is a concrete, auditable discovery programme that can accept a null result and preserve the data needed to investigate the next idea.
