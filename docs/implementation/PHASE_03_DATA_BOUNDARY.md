## Sampling, control and target contract

Discovery is an interval enumeration under Gamma closed=false, not an atomic snapshot.
Keep its complete scope separate from the deep sampled population and public display limits.
Preserve the stored seed, strata, exact rational first-stage/conditional probabilities, all
exclusions, missing category/group metadata, overlapping roles and unfilled control slots.
D097/D114 restrict the declared deep population to future-or-unknown stated end; those
exclusions have zero inclusion probability. endDate does not prove active trading. Do not
pool populations without explicitly accounting for these differences.

Only known, untriggered, assessed, timely members can be controls. Unknown/unavailable/stale
is not negative. Preserve actual pre-t0 input availability and freeze/save clocks. Outcome
selection uses the frozen first valid two-sided noncrossed quote at/after origin+horizon
within tolerance; retain pending/late/closed/missing cases separately. Midpoint movement is
not executable return. Deduplicate markets, account for repeated/shared events and dependence;
these tiny pilots do not establish an effective independent sample size or predictive edge.
