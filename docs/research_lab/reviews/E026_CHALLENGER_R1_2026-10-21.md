## Required fixes before freeze
1. **"Not supported" uses a less conservative interval than "Supported"** (`copy_skilled_analysis.py:310-312`
   `ci95_boot`, event-only; `diff_stats` has none). Use upper = max(bootstrap upper, R + t·se_event, R + t·se_twoway)
   for both tests; update 7.3.
2. **The registered run can count nothing:** q0543 `argv` lacks `--trials`; `analyze()` returns `{"status":"no_data"}`
   (`:355-356`) with no Holm or verdicts. Add `--trials ../docs/research_lab/trials.jsonl`; no-data returns both tests
   Unavailable, p = 1, n_tests = 2.
3. **Pins do not cover every input:** (a) `cost_model_calibration_v1.json` (impact table, `analysis.py:34`) not in
   `CODE_FILES` / spec: pin and check its sha256 in `analyze`; (b) `load_skillset` skips the hash check when
   `skillset_sha256` is falsy (`copy_skilled.py:254`): `load_spec` must refuse a pinned spec with null `skillset_sha256`
   or empty `code_sha256`; (c) `analyze` never filters entries / resolutions by `spec_sha` / `code_sha` (`:347-354`).
4. **Shared pinned modules unprotected** (`wallet_skill.py`, `wallet_skill_dev.py`, `costs.py` are used elsewhere): a
   unit test asserting the pinned hashes; a "frozen until 2026-12-07" note (ledger, CLAUDE.md / AGENTS.md); q0543 runs
   from a worktree at the pinned commit.
5. **Labeller / recorder memory unchecked at 21-day size:** `label_resolutions` reads all columns (`:912, 923`);
   projected about 180k signal rows and 700k entry rows, likely above q0542 `mem_mb` 300. Add `usecols`; run `run`,
   `label`, `analyze` on a synthetic store about 7.5x the census size and size `mem_mb` / `as_cap_mb` from it.
6. **End-date gate (c4f3549b): accept with changes.** The gate cannot change a label, opens >= 7 d before the cutoff and
   is market-level and arm-blind. But it uses the **max** recorded end date (`:927`), so a later end-date extension can
   hold back an early-resolved market past the cutoff: disable the gate from cutoff - 7 d; log due-but-unasked and gated
   counts every pass.
7. **Collectors can fail before the window opens** (exit 75 before 10-25; 48 consecutive tempfails -> failed): set
   `not_before` = REGISTERED_UTC for q0541 and REGISTERED_UTC + 6 h for q0542; a re-promotion rule within 48 h.
8. **Control-side event dependence (Q12) into the p rule:** split each pair's linearised score into a skilled piece
   (its event) and control pieces (each control's event, weight 1/m), sum by event regardless of side, add that
   cluster-robust t and the matching event bootstrap to the max rule. Not connected components.
9. **E026-C compares different kinds of trade:** skilled = first observed in-window trade of each (wallet, market)
   (`:297`); controls may be adds / closes (`:308`). Add a causal within-sample flag "this wallet has an earlier visible
   trade in this market among the sample's 500 rows", computed from raw rows before the seen-before filter
   (`:410-413`), into the matching cell. Also partly answers Q1.
10. **Document vs census:** Q2 "about 2-4 h" (census median 6.6 h); 4.1 trade age "minutes to about 2 h" (p50 4.5 h,
    p90 16.3 h); 7.5 says q0544 ran on afac80d4 (census `git_commit` 7d2eac8b; library hashes identical); "2,946 before
    the wallet-day cap and the one-per-(wallet, market) rule" (the latter is applied at signal level); ordering
    disclosure: gates entered the spec at 3dd2d7ef (08:52Z) and the doc at aba32281 (08:56Z); cite both and the host
    timestamp of the earlier census run.
