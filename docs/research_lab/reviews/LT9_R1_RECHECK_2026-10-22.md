## Required before the freeze
1. **CH215 picks controls in the wrong order (causality).** Controls are assigned in order of `T_e`; an end with a later
   `T_e` can be decided before an earlier-`T_e` end has been listed, so its controls (and a `no_control` drop) would depend
   on a feed listing made after its own decision, breaking section 5 (line 830). **Fix:** assign greedily in decision-time
   order, considering only ends already decided.
2. **CH214's split is not at zero change.** `max(0, zdD)` splits at the census centre; if the centre is below 0, small
   departures (the fill channel) leak into the arrival term. **Fix:** `zdD± = max/min(0, dD) / scale_census`; same for the
   lag twin and worlds 5–8 and 13. The centred `zdD` stays for S2 and the gates. Planning arithmetic unchanged.
3. **Feed end times undefined.** State route A's "slot k + 2's start" as an exact instant (e.g. nominal
   `grid0 + 2 h × (k + 2)`). Declare a parse rule for the feed's `end_date` (date-only values, sentinels). Route A: the
   earliest instant consistent with the served value. CH215's `T_e`: declare the instant and report a sensitivity. CC9 and
   CR9 print the date-only and sentinel shares.
4. **CH214's "material" label mislabelled.** The 2.2-unit `zdD+` scale is conservative for the gate, but calling it a
   "tercile contrast" is wrong (the label is ~2x easier to earn than at the real contrast). Name the scale, report the census
   `zdD+` gap between `zdD`'s top and bottom terciles beside it (~1.09 at planning); the 1.0c power run states this scale.
5. **Wrong reason for the 0.95 in-band share.** "Half-spread < v at both sweeps" is the complement of the level state
   s ≥ 2v; the 1–3% figure is the crossing rate. Correct the reason and add a sensitivity: at 0.80 the MDE is 0.61c and the
   F-MDE 0.86–1.02c (fails at r = 0.3). Text only; no gate changes.
6. **Three ambiguous definitions:** which filters set a market's first unit (`band_changed`, `ctrl_band_uncovered`?);
   which units count in `relpos_k`'s "strictly earlier units" (`panel_switched` included?); which reward rows feed the
   control-cell median (carry-rewarded eligible rows of capture k, regardless of `panel_m`?).
