## SHOULD

1. **`fees_enabled` parsing for L1 (l. 239-240).** `taker_rate` returns 0 only when it is given `fees_enabled is False`, and the sidecar holds a string. Add: "`fees_enabled` is passed as False when served and not `_truthy`, True when served and truthy, None when missing." Also disclose that S4 `fee_free` units of the `rate_zero` kind (`fee_class` l. 116) still carry L1 = the docs rate unless the flag is off.
2. **Denominators.** Coverage (l. 397) and coarse rule 3 (l. 479) use "eligible units", which leaves `no_favourite` ambiguous. Use "M2 units (passed E1-E9; `no_favourite` excluded and its fetch coverage printed separately)".
3. **Bootstrap for split cells (l. 319-320).** "The same draws serve every split" contradicts "a split's CI resamples its own events". Declare one. Suggested: "the same event draws restricted to the cell's units; draws with no final-state unit in the cell are counted and left out of that cell's percentiles." Also disclose that the day-block bootstrap splits events whose units have k on different days.
4. **Look-back fold timing.** 9.2 processes only window captures. Add: "J1's first pass, after the registration commit and before the first window capture is processed, folds the look-back span in order. A slot whose capture is absent or already removed by retention at that pass is `missing_lookback_slot`." The phrase "the count is printed" (l. 84) should say the slot count; markets that were overdue only in a missing slot cannot be counted.
5. **S3 `unknown` "including empty" (l. 291) cannot occur.** E5 needs `crypto_class` = `non_crypto`, which requires a non-empty `fee_category` (`live_tests11_base.py:718-727`). Say "structurally excludes empty".
6. **Funnel exhaustiveness.** A market that is in the overdue-seen set, not overdue at k−1 because its `end_date` moved, and overdue again at k is silently not a candidate. Count it as `reoverdue_seen`.
7. **`not_found` single-id re-query (l. 465-466).** Re-query both with and without `closed=true`. Only two HTTP 200 empty answers make a unit `not_found`. Whether Gamma returns archived or closed markets to `/markets?id=` is unverified, and a false `not_found` biases `theta_NF` downward.
8. **S5 "YES/NO"** means outcome-0 and outcome-1 (l. 113, 364). Say so, for non-Yes/No binaries.
9. **J0 status forms (l. 418).** No J0 output can change the E6 whitelist or the P tokens, so state that unforeseen forms stay `uma_other_*`.
10. **Planning figures (l. 487-490).** Align with R1's recompute: independent-unit SE 0.71-0.99c, half-width 2.1-4.9c. They are not load-bearing.
