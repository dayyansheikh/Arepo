## Label deviations (1.9, disclosed)
- *CLOB-disagreement sensitive* (CH232): not computed. LT11 has no feed reader (8.2 names the feed for CH232's CLOB sensitivity only); the label is never assigned. A reader for it would be new code after this freeze check and would need its own check.
- *underpowered*: computed only once `census_fixed.<test>.mde_c` is filled (the census writes it); `G` = the primary's UTC days, `SE_day` the day-clustered SE.
- *informed (X)*: from `spec.informed_labels`, filled at the pin from the ledger (the analysis cannot itself know `T_E015` / `T_E022` timings).
